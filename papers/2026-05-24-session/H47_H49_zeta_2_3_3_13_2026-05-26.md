## 1. Spectral zeta function ζ_Δ(s) — standard recap

For a positive elliptic operator Δ on a closed d-dim Riemannian manifold M, with eigenvalues {λ_n > 0},

  ζ_Δ(s) = Σ_n λ_n^{-s},  Re(s) > d/2.

By Seeley (1967) it admits a meromorphic continuation to ℂ with **only simple poles** at
  s = d/2, d/2 - 1, d/2 - 2, … (skipping s = 0, -1, -2, … in even d).

Residues are linear combinations of Seeley-DeWitt coefficients a_k:
  Res_{s = d/2 - k} ζ_Δ(s) = a_k(Δ) / Γ(d/2 - k),
with a_0 = vol(M)/(4π)^{d/2}, a_1 ∝ ∫ R, a_2 ∝ ∫(R² terms + ½R_{μν}² - ⅓R_{μνρσ}²).

For **d = 4**: poles at s = 2 (residue ∝ vol), s = 1 (∝ ∫R) ; ζ_Δ(0) finite (conformal anomaly), ζ_Δ'(0) → functional determinant.

The famous κ_FP = 1/6 of our program already matches a_2/R = 1/6 for scalars (Birrell-Davies eq. 6.51, Seeley-DeWitt-Gilkey).

## 2. Test H47: is 2/3 a natural pole for fractal d_s = 10/3 Laplacian?

If H46 (Gribov fractal d_s = 10/3) holds, the meromorphic continuation of ζ_{Δ_FP}(s) on the conformally-fractal Coulomb slice should have poles at

  s = d_s/2 - k = 5/3, 2/3, **-1/3**, -4/3, …  (k = 0, 1, 2, 3, …)

**Crucial observation**: ξ★ = 2/3 = **exactly the k=1 pole** s = d_s/2 - 1 when d_s = 10/3.

Residue at s = 2/3 is proportional to ∫ R · μ_{Hausdorff}, the *fractal scalar curvature*. In analogy with d=4 (residue at s=1 ∝ ∫R), this would identify

  ξ★ = position of the **scalar-curvature pole** of the FP Laplacian on the fractal Gribov region.

For Teplyaev-style fractal Laplacians (math/0505546), poles lie in an arithmetic progression spaced by (log scaling factor)/(log spectral ratio). The match s = 2/3 here requires d_s exactly 10/3 — i.e. H47 is *logically equivalent* to H46 at the linear pole level.

**Sanity check on other anchors**:
- κ_FP = 1/6 — *not* a pole, but matches a_2 Seeley-DeWitt residue *coefficient* (already in MEMORY κ_FP entry).
- 9/10 — would need d_s = 19/5; doesn't fit clean arithmetic progression with 10/3.
- 1/4 — fits d=1/2 fractional Laplacian (s=1/4 pole if d_s=1/2). Disconnected from gauge sector.

So H47 is **internally consistent only with H46** ; it does not independently *predict* d_s = 10/3, but it ties two conjectures together economically.

## 3. Test H49: sin²θ_W = 3/13 from SU(3) representation theory?

Proposed split: 13 = dim_fund(3) + dim_adj(8) + rank(2). Three caveats:

(a) "rank" is dimension of Cartan subalgebra (= 2 for SU(3)) — *contained in* adjoint, double-counting. Standard "total dof" is 3 + 8 = 11, not 13.
(b) Killing form Casimir of fund: C_2(F) = (N²-1)/(2N) = 4/3 ; of adj: C_2(A) = N = 3 ; sum 4/3 + 3 = 13/3 — note 13 *appears* but as denominator.
(c) Ratio C_2(F)/[C_2(F)+C_2(A)] = (4/3)/(13/3) = **4/13**, not 3/13. dim(F)/[dim(F)+dim(A)+rank] = 3/13 is the only path giving 3/13 exactly — combinatorial, not Casimir.

**Literature cross-check** (this is the strongest result of the test):
Frampton-Mohapatra-Suh, *Prediction of sin²θ_W in a Conformal Approach* (hep-ph/0104211, 2001) predict **sin²θ_W ≃ 0.227** from a Type IIB orbifold AdS_5 × S^5/Γ construction with gauge group SU(4)_C × SU(2)_L × SU(2)_R. The value 0.227 differs from 3/13 = 0.2308 by 1.7%, but the *rational* structure 3/13 is not stated explicitly in that paper.

Standard GUT predictions: SU(5)/SO(10) give **3/8** at unification, RG-evolved down to ~0.23 at M_Z. The fractional **3/13** as a *boundary* (tree-level) rational has no canonical GUT origin in the literature surveyed.

**Verdict on H49**: the value 3/13 is *numerically* a strong match (0.04%), and *combinatorially* expressible as dim(F)/(dim(F)+dim(A)+rank). But no rigorous derivation: rank is double-counted in standard reps. Best status — **suggestive numerical anchor**, awaiting a coset-space or Pati-Salam re-derivation.

## 4. Bonus — Seiberg-Witten

In N=2 SU(2) SYM the modular function τ(u) has special values at u = ±Λ² (monopole/dyon points) ; the prepotential expansion gives ratios 1/2, 1/3, 2/3 in instanton corrections (Seiberg-Witten 1994, Nekrasov 2002). A literal identification ξ★ = 2/3 with an SW-modular value is **tentative** — would require explicit re-computation on the SU(2) Coulomb branch (out of scope here).
